## Caveats

GitHub alone cannot establish employability: employers will still weigh résumé, work history, interviews, communication, collaboration, and role fit. A GitHub profile is best treated as supporting evidence, not a substitute for those signals. [dev](https://dev.to/profydev/this-survey-among-60-hiring-managers-reveals-don-t-waste-your-time-on-a-react-portfolio-website-17ge/comments)

The profile also has some presentation friction: “jzombie,” 97 repositories, and many small utility projects can make it harder for a recruiter to quickly identify the strongest work. The profile links to `zenosmosis.com` and an organization account, but the main page itself does not clearly summarize target roles, notable achievements, or a curated “best work” path. [github](https://github.com/jzombie)
